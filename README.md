# Creator Rights Issue Spotter

A seven-question educational issue spotter for creator, AI, disclosure, likeness, music, jurisdiction, and platform review. Built by RN Collins.

**Live:** https://aloha-creator-rights.vercel.app

## Repository contents

`components`, `lib`, `next.config.js`, `package-lock.json`, `package.json`, `pages`, `public`, `styles`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
